
# Smart Parking Management System

## Project 12

A C programming project that manages parking slots
and allocates suitable spaces to vehicles.

## Features
- Display parking slots
- Park bikes, cars and SUVs
- Greedy slot allocation
- Search vehicles
- Remove vehicles
- Calculate parking fees
- Day and night rates
- Overstay fines
- Expand parking slots
- Occupancy and revenue reports

## Concepts Used
- Variables
- Conditional statements
- Loops
- Arrays
- Structures
- Functions
- Pointers
- Dynamic memory allocation
- malloc()
- realloc()
- free()
- Greedy algorithm

## Language
C Programming
